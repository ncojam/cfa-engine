# Портреты: формат движка <-> читаемая лента

    cd /cfa_engine/editors/portraits
    python3 portrait_unpack.py        # project/images/charNN.bmp -> ./charNN_faces.bmp
    # ... рисуешь в charNN_faces.bmp (эмоции 72x80 слева направо) ...
    python3 portrait_pack.py --dry-run
    python3 portrait_pack.py          # ./charNN_faces.bmp -> project/images/charNN.bmp

Номера можно перечислить: `portrait_unpack.py 0 9`, `portrait_pack.py char04`.
Python 3, без сторонних библиотек.

* Если в ленте эмоций меньше, чем в листе, недостающие (последние) остаются из оригинала.
  Удалить их можно только явно: `portrait_pack.py --trim`.
* Число эмоций = (высота − 8) / 48 у листа, ширина / 72 у ленты. Новую эмоцию можно
  дорисовать справа — лист вырастет на 48 px.
* Формат сохраняется: 24-битный лист -> 24-битная лента -> 24-битный лист. Лента может быть
  пересохранена редактором в любом формате (8/24/32 бита) — при сборке она приводится к формату
  оригинала. Если оригинал 8-битный с палитрой, цвет не из палитры = ошибка с координатами.
* Тайлы, которые игра не показывает (техполоска, пустые куски блока), при сборке берутся
  из текущего `project/images/charNN.bmp` без изменений.
* Перед перезаписью оригинал копируется в `portraits/backups/<дата>/`.
* Распаковка сама проверяет «туда-обратно» и ругается, если не сошлось.

## Большой арт (x10) → лента

* `charNN_faces_big.bmp` рядом с лентами: эмоции 720x800 слева направо, фон — маджента.
* В редакторе диалогов → «Портреты» → персонаж → **«Большой → лента»**: ресайз /10 (тент-фильтр,
  каждая эмоция отдельно; внешний контур по мадженте не сглаживается), затем приведение к палитре
  из первых двух тайлов 8x8 `project/images/chr_spr_witch.bmp` (шахматный дизеринг, если цвета нет).
* **«Пиксельарт-прогон»** по ленте: убирает «локти» лайна, выравнивает самые выбивающиеся ступеньки
  (2,3,2 → 2,2,…), во внутренних уголках лайна ставит цвет потемнее из палитры.
* Обе кнопки делают бэкап ленты в `portraits/backups/<дата>/faces/`. Лист (игра) потом — «Лента → лист».
